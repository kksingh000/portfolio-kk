One-line: the generic surface — experience entries, contact block, popup body.

```jsx
<Card elevation="raised" interactive>…</Card>
<Card theme="deep" elevation="float">…</Card>
```

- `elevation="float"` only for things genuinely lifted off the scene (popups, the ring's focus panel).
- `focused` is for programmatic focus (ring front-center slot), `interactive` for pointer hover.
